# 3D 头盔 → TuZhi 游戏体素图纸工作流

## 可直接交给新任务 / Cursor 的说明

目标：为 `D:\Project\TuZhi` 制作可预览、可试穿的 **真实 3D 头盔体素图纸**。

核心原则：

- **只使用完整 3D 模型**（必须有前、后、左、右的真实几何；优先带内腔/壳体）。
- **禁止**由单张概念图加厚、拉伸或生成 2.5D 浮雕来冒充头盔。
- 成品造型方向：蓝灰硬表面装甲、深色面罩、冰蓝发光细节；当前 Khronos SciFi Helmet 仅用来验证流程，不是最终美术定稿。

### 1. 获取模型

1. 在可商用或 CC0/CC-BY 许可的来源寻找 `.fbx`、`.obj`、`.glb`、`.blend` 的完整头盔模型。
2. 下载前记录来源链接、作者、许可和署名要求；不使用“仅个人使用”、`NC`、许可不明或图片素材。
3. 原始模型和许可文件统一放入：
   `D:\AI3DTools\Imports\<模型名>\`
4. 不要直接把原始模型塞进 Unity 的 `Assets`。

### 2. 导入前检查

确认模型是可用的三维对象，而不是平面、贴图卡片或只有正面：

- 检查前后左右轮廓和底部开口/内腔。
- 检查网格是否可读取、三角面是否存在、尺寸是否合理。
- 统一 Y 轴向上；确认正面方向，必要时记录旋转。
- 检查材质与贴图。体素化时保留材质分区：外壳蓝灰、面罩近黑、发光细节冰蓝。

### 3. 体素化

1. 以**网格表面体素化**，不从渲染图或概念图反推体积。
2. 先做约 `39 × 49 × 43` 到 `48 × 60 × 60` 的验证分辨率；根据细节再增减，单轴不能超过 256（`.vox` 限制）。
3. 维持外壳、面罩、耳部/下颌细节和后脑轮廓；不要把整个头盔实心填满，避免抹掉壳体结构和开口。
4. 导出：
   - TuZhi 的 `VoxelBlueprintAsset`（`.asset`）
   - 对应 MagicaVoxel `.vox`
   - 同名静态预览 `<资产名>_Preview.png`

### 4. TuZhi 资产目录与命名

每个模型单独放到：

`D:\Project\TuZhi\Assets\VoxelBlueprints\Imported3DModels\<模型名>_VoxelV01\`

建议命名：

`PmUnitVoxelHelmetStyle_<模型名>_VoxelV01`

目录内至少应包含：

- `PmUnitVoxelHelmetStyle_<模型名>_VoxelV01.asset`
- `PmUnitVoxelHelmetStyle_<模型名>_VoxelV01.vox`
- `PmUnitVoxelHelmetStyle_<模型名>_VoxelV01_Preview.png`
- `SOURCE.md`（来源、许可证、作者/署名和处理说明）

`VoxelBlueprintAsset` 的脚本 GUID 为 `20a00d18131e9354a944475a25bcdc49`。若从外部生成 YAML 资产，必须使用既有资产的序列化格式；优先通过 Unity 的导入工具生成，避免手工破坏引用。

### 5. Unity 中验证

1. 让 Unity 完成导入并检查 Console，不能引入新的编译错误。
2. 选中 `.asset`，确认 Inspector 显示静态预览 PNG；实时 3D 预览会卡顿，不要恢复为 Inspector 实时渲染。
3. 在 `Tools/Voxel Blueprint Authoring/Open` 打开图纸，绕视确认前后左右都存在、面罩位置正确、开口/空腔未被错误填满。
4. 在游戏试穿流程中挂载，检查尺寸、朝向、头部偏移和遮挡关系。
